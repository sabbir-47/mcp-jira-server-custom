Deployment and Lifecycle Stale Issues Analysis

Executive Summary

This report analyzes 24 stale Telco priority bugs affecting OpenShift versions 4.14, 4.16, and 4.18, where no comments have been posted in the last 5 days. The analysis reveals several concerning patterns requiring immediate attention.

**Critical Blockers and Resource Constraints:** Hardware availability is blocking critical debugging work on HP ARM SNO boot order issues (OCPBUGS-50689), where the cnfdg37 test system is allocated to other priorities. This issue has a partial workaround but no root cause resolution. Multiple issues are stalled waiting for customer responses, including HP ARM hardware SSL certificate problems (OCPBUGS-48534) and BMH scale operation errors (OCPBUGS-36197), with some waiting over 89 days for customer data.

**Work in Progress and Modified Issues:** Active development continues on BIOS settings optimization (OCPBUGS-54677) with a candidate patch ready to reduce server downtime during firmware updates. However, 4 issues marked as MODIFIED status have stalled without closure, including fixes that were dropped from advisories (OCPBUGS-54381, 48088) and others with only automated bot activity (OCPBUGS-56865).

**Documentation and Tooling Gaps:** The cluster-compare tool requires multiple enhancements to handle NetworkAttachmentDefinition annotations, PerformanceProfile parameters, and non-RT kernel configurations. The RAN Reference Design Specifications (RDS) has identified documentation gaps around Console Disable settings, cluster capabilities (OLM/Ingress), and ClusterInstance scale data that remain unaddressed for extended periods.

**Component Distribution and Priority:** GitOps ZTP component accounts for 58% of stale issues (14 bugs), indicating potential resource constraints or complexity in this area. Bare Metal Hardware Provisioning represents 25% (6 bugs). The DPDK ARM MLNX driver issue was resolved in the Konflux transition but will resurface in 4.19.z and 4.20+ releases when RHEL base images upgrade from 9.4 to 9.6.

**New Issues Requiring Triage:** 42% of stale issues (10 bugs) have zero comments and require initial triage and assignment, including SR-IOV annotation cleanup, cluster-compare tolerations, and reference configuration validation gaps.

Current State: Analysis reveals 24 out of 24 issues (100%) in a stale state across 4.14, 4.16, 4.18 releases, requiring immediate attention to maintain development velocity and customer satisfaction.
